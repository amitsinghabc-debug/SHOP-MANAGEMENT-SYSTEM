# SHOP-MANAGEMENT-SYSTEM
Shop bill Management System
This project is a simple billing application built with Python. I created it as part of a college assignment.
It helps shopkeepers quickly generate bills by entering items, quantities, and prices.

Features
Add as many items as needed
Each item includes a name, quantity, and unit price
Calculates subtotal for each item and a grand total for the bill
Automatically saves every bill in the bills folder
Bills are stored with the current date and time, ensuring each file is unique
