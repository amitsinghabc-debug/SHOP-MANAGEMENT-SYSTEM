Project Statement – Shop Management System (Python)
Problem Statement
In many small shops, bills are still written on paper and totals are calculated manually.
Because of this, small mistakes happen and it also takes extra time.
To solve this, I created a basic Python program which helps in generating a bill quickly by entering items, quantities and prices.
The program also saves the bill into a text file so the shopkeeper can check it later whenever needed.

Scope of the Project
What is included
Asking the user how many items they want to enter
2.Taking item name, quantity and price
Auto–calculation of total amount
Displaying bill in a clear format
Creating a bills folder automatically
Saving each bill with a unique timestamp
What is not included
No GST or tax calculation
No discount features
No database or inventory system
No graphical user interface (command line only)
Not suitable for big shop management
Target Users
Small shop owners who want a simple quick billing solution
Students who are learning Python basics
Anyone who wants to practice file handling and loops in Python
High Level Features
Simple and easy input system
Input validation for quantity and price
Neatly formatted bill output
Automatic creation of bill text file
Code is fully beginner–friendly and easy to understand
Purpose of the Project
The main aim of this project is to practice Python programming concepts like loops, condition checking, functions, and file handling while building something meaningful and useful in real life.
